# Third-party dependencies

- `mcp`, the Model Context Protocol Python SDK, is installed separately by the package manager. The upstream SDK is distributed under MIT. [Upstream license](https://github.com/modelcontextprotocol/python-sdk/blob/main/LICENSE)
- `marvelous-designer-mcp` provides a separate local listener. The verified listener came from version `0.3.0`, distributed under MIT by ysk424 and Laboon2501 and contributors. [Upstream license](https://github.com/Laboon2501/MarvelousDesigner-MCP/blob/main/LICENSE)
- The native bridge is built using Qt development headers and the Windows toolchain. Obtain those inputs and Marvelous Designer independently under their respective terms. [Qt licensing](https://doc.qt.io/qt-6/licensing.html)
